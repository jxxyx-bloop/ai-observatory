Know what to change about your AI usage.

Every other token tracker is an odometer — it tells you how much you spent. This one is a coach: it reads the transcripts your coding agent already wrote to disk and turns them into ranked, evidence-backed changes with a number attached.

Built for how developers in Southeast Asia and China actually buy AI: flat monthly plans, tokens priced by the hour, and a currency that isn't the dollar. Collection costs zero tokens — no API key, no proxy, no account, no network.

What a finding looks like

HIGH You are buying tokens at peak rates you did not have to pay ~$34/mo

61.4% of your spend on time-priced vendors (deepseek, zhipu) landed inside a peak window, where the same tokens cost up to twice the off-peak rate. Over this period that timing cost about $68.20 more than running the identical work off-peak.

→ Peak windows are published and narrow. Anything that does not need you watching — test generation, migrations, doc sweeps, bulk refactors — can be queued for an off-peak hour at no cost to you. Interactive work is worth the premium; a batch job is not.

Fifteen deterministic detectors. Every finding carries the evidence behind it, an action, a confidence level, and — where it can be defended — what a fix is worth per month. A materiality gate demotes anything under $15/month, so the top of the list always means something. Healthy usage is reported as healthy — a tool that invents problems to look useful is a tool you stop believing.

Why this is not another token counter

Peak / off-peak

Priced on your vendor's clock

DeepSeek bills full rate 01:00–04:00 and 06:00–10:00 UTC and half otherwise; GLM peaks 14:00–18:00 UTC+8 on weekdays only. For anyone in UTC+7 to +9 that second window is the working afternoon. No other open-source tracker models this.

Plan value

Not a fake dollar figure

On an $18/month plan, "you spent $412" is a shadow price, not a bill. The number that matters is 23× return — or, when it goes the other way, "you are paying for headroom you never use."

Cache economics

Per-vendor, not per-convention

The 0.1× cache-hit discount is an Anthropic convention, not a law — Kimi K2.6 sits near 0.074×. Cache is where the money is, so a wrong multiplier misprices the most important number on the page.

Local currency

Thirteen of them

IDR, VND, THB, PHP, MYR and more — framed against a median local day rate, because $412 means something very different in Jakarta than in San Francisco.

Contribution

Your tool is a JSON file away

A provider is a declarative spec plus a fixture — no engine code. If you use Lingma, Qwen Code, CodeBuddy or Comate, you are the only person who can add it correctly, and it costs you one file.

Community

Ranked on efficiency, never spend

Existing leaderboards rank total tokens burned — the top of that board is whoever wasted the most. We rank cache reuse, tokens per change and peak discipline. Improvable, and fair across budgets.

Privacy is a mechanism here, not a promise

Nothing leaves your machine unless you edit a file to say so.

  • Never stored, anywhere: prompt text, completion text, thinking content, file contents, tool argument values, shell commands, absolute paths.
  • Enforced at the parse boundary, not by a later redaction step — a leak past it is a bug, not a policy question.
  • The rendered dashboard makes zero external requests. No CDN, no fonts, no analytics. So does this page.
  • If you ever opt in to the community layer, the payload is 633 bytes of bucket indices — no repository name, no session id, no identifier, no raw value. observe.py share prints the whole thing and has no network code path.
