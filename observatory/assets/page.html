What to change

Ordered by severity, then by what it is worth. Every finding names its evidence. Computed once over the whole window — the filters above do not change it.

How this was measured. Every number comes from the token accounting the API already returned, recorded in local Claude Code and Codex transcripts. Collection reads those files and costs no tokens. No prompt text, completion text, file contents, shell commands, or absolute paths are stored or shown — counts, model names, tool names, and derived repository and folder labels only.

Cost is an estimate. Token counts are exact; dollar figures apply a local price list (verified ) and are notional on a seat plan. Treat spend as a relative measure of where effort goes, not a bill.

How work is attributed. A turn is credited to the repository it ran in, or to the first real repository whose files it touched. Turns that name no file inherit the nearest attributed turn in the same session; a session that touched nothing stays unattributed. Scratch and config folders lose ties to real repositories. Lanes are inferred from engine/topology.json — transcripts carry no account identity, so a lane is a rule you write, not a fact the provider reports.
