How this was measured

  1. No prompt, completion, file, command, or path content is ever stored or shown. Only counts, model names, tool names, and derived repository or folder labels are kept — read from the token accounting the API already returns, in local Claude Code and Codex transcripts. Collection costs no tokens.
  2. Cost is an estimate, not a bill. Token counts are exact; dollar figures apply each vendor's public API list price (verified ) — the highest rate anyone pays, before enterprise or subscription discounts. Treat spend as a ceiling, and as a relative signal of where effort goes.
  3. Work is attributed by repository, not by account. A turn credits to the repo it touched, or inherits the nearest attributed turn in the same session; an untouched session stays unattributed, and scratch or config folders don't tie to real repos. Lanes come from a rule you write in engine/topology.json — transcripts carry no account identity.
  4. The page is self-contained and reproducible. No external requests, fonts, scripts, or analytics. Generated UTC — regenerate anytime with python3 observatory/observe.py all.
